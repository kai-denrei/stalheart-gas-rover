# Three-plane flip practice

Open **http://localhost:8166/?mode=kickflip**, or choose **Trick lab · Flip Lab**. The URL remains compatible with existing links. This practice mode keeps damage disabled.

Boost clear of the surface, then use **Q/E for Coronal Flip**, **W/S for Sagittal Flip**, or **A/D for Transverse Flip**. Tap to build spin, release to coast, then use the opposite key to counter. Combine planes for mixed figures. Space supplies lift, Shift thrusts down, X brakes movement, and C restores level stabilization. Ground contact switches W/S and A/D back to driving and steering; Q/E is inactive on the ground.

There is no canned flip animation or automatic counter-burst. Balanced reaction jets apply real torque and use gas. Signed quaternion winding verifies each complete turn. The CRT callout names the plane; repeated turns increase the combo. The practice HUD follows the dominant rotation plane.

See [flight and race rules](flight-and-traction.md) for scoring, flag-height gates, out-of-bounds allowances and high-speed multi-flip wrecks in races.
